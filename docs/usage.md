Execution
----------
Place the source code files in the desired location and execute quantumswitch.py through python interpreter.
Example:
```shell
python3 quantumswitch.py
```

Network topology and parameters must be placed in a file named **properties.cfg** in the same directory. Some examples are documented in the [examples](../examples/) directory.

Once executed results will be stored in csv format in the same folder as source files in a file called *results.csv*.
