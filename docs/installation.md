Installation
------------
Simulator is shipped as source code files that can be executed with a Python interpreter.
In Ubuntu:
```shell
python3 quantumswitch.py
```


Software requirements
---------------------
- Operating System: Ubuntu 20.04 or later
- Python <= 3.11
- Python libraries: 
    - netsquid 1.0.7 or later: Follow instructions in NetSquid's website to install
